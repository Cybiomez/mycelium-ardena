# Changelog

## Не выпущено — архив сессий

Нужен ClaudeDaemon ≥ 0.4.0 (ТЗ `~/projects/notes/tz-session-archive.md`).
- `/delete` в теме: тема удаляется, сессия целиком — в архив демона на 90 дней, потом безвозвратно.
- `/fresh` в теме: та же тема, новая сессия; прежняя — в архив; новая получает затравку (заметка «Контекст» по строке «Тема в боте», открытые пункты чек-листа). `/back` — вернуть прежнюю.
- `/archive` в General: список архива со сроками и кнопками «Вернуть» (сессия возвращается с новой темой).
- Синхронизация не заводит тему под сессию, которую бот в этот момент переносит.
- MCP-инструмент `topic_delete` — удалить тему по точному названию (только по просьбе Алексея).

## 0.1.0 — не выпущено

Фаза 1 ТЗ: диалог.
- Темы супергруппы = сессии ClaudeDaemon; `/setup`, `/new`, `/attach`, `/rename`, `/topics`; закреплённая шапка темы.
- Одно живое сообщение на ход: статус, стрим ответа, «Стоп», свёрнутые «Размышления» и «Ход работы».
- Конвертер markdown → HTML Telegram, деление длинных ответов, файл `.md` для очень длинных.
- Очередь: 👀 на сообщении в очереди, `/queue` с отменой.
- `/settings` и `/defaults`: модель и effort на сессию из списка моделей демона.
- `AskUserQuestion` кнопками (одиночный и множественный выбор, свой ответ).
- Чужие чаты (`@бот /команда`, `@бот текст`), личка, инлайн-режим, буфер контекста, копии в TGChat.
- Тихие часы, `/usage`, `/context` со сжатием, `/stop`, `/panic` + `claude-tg unlock`.
